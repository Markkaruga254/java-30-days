# Day 26: Securing a Java API

## Plan

**Learn (30 to 45 min):** Spring Security basics; password hashing with BCrypt; JWT authentication; role-based access; the OWASP Top 10 as it applies to Java (injection, broken access control, insecure deserialization, secrets in code).

**Build (60 to 90 min):** Add registration, login and JWT-protected endpoints with two roles. Write tests proving that a user cannot access another user's data. Then write one deliberate vulnerability (for example an insecure direct object reference), exploit it, and patch it.
